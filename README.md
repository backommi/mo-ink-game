# 墨染 - 水墨消除游戏

🎨 控制墨滴下落，创造独特的水墨画作

## 游戏特色

- **水墨意境**：将消除游戏变成创作游戏
- **晕染效果**：真实的墨迹扩散模拟
- **动态分数**：根据墨迹面积和风险系数计算分数
- **墨溢机制**：控制墨迹程度，避免游戏结束

## 操作说明

- **← →**：左右移动墨滴位置
- **↓**：加速下落
- **空格**：收墨消除
