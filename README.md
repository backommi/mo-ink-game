# 墨染 - 水墨消除游戏

🎨 控制墨滴下落，创造独特的水墨画作

## 🎮 游戏特色

- **水墨意境**：将消除游戏变成创作游戏
- **晕染效果**：真实的墨迹扩散模拟
- **动态分数**：根据墨迹面积和风险系数计算分数
- **墨溢机制**：控制墨迹程度，避免游戏结束

## 🚀 快速开始

### 本地开发
```bash
npm install
npm run dev
```

访问：http://localhost:5173/mo-ink-game/

### GitHub 部署
```bash
# 1. 配置 GitHub 仓库（参考 DEPLOY.md）
# 2. 部署
npm run deploy
```

访问：https://your-username.github.io/mo-ink-game/
